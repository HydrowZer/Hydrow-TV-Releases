# Hydrow TV — téléchargements

Versions publiées d’**Hydrow TV**, le client Twitch et YouTube : directs
Twitch avec tchat, multivue et StreamGuard, vidéos YouTube en lecture native,
recommandations sans fin, Mix, SponsorBlock et sous-titres traduits.

## Windows

Télécharger la dernière version dans
[**Releases**](https://github.com/HydrowZer/Hydrow-TV-Releases/releases/latest) :

- PC Intel ou AMD : `Hydrow-Setup-…-x64.exe`
- PC Windows ARM : `Hydrow-Setup-…-arm64.exe`

Windows 10 ou 11, 64 bits. L’installation se fait pour l’utilisateur courant,
sans droits administrateur. Les installateurs ne sont pas signés : Windows peut
afficher un avertissement au premier lancement (« Informations
complémentaires », puis « Exécuter quand même »).

Les mises à jour se font ensuite depuis l’application : elle cherche la
dernière version publiée ici, la télécharge, vérifie son empreinte SHA-256,
l’installe et redémarre. Comptes, historique et réglages sont conservés.

Chaque version publie ses empreintes dans `SHA256SUMS-<version>.txt`.
